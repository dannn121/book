# 나의 가계부

정적 HTML 한 파일로 동작하는 개인 가계부 앱입니다. 빌드 과정이 필요 없습니다.

## 무엇이 바뀌었나 (Claude 아티팩트 → 실제 사이트)

- 데이터 저장 방식을 Claude 아티팩트 전용 DB(`claude.use('db')`)에서 브라우저 `localStorage`로 교체했습니다. 이 기기(브라우저)에만 데이터가 저장됩니다.
- 구글시트 새로고침 기능은 코드 그대로 유지했습니다. Claude 아티팩트 안에서는 외부 스크립트 로드가 보안상 차단돼 있어 항상 실패했지만, 실제로 배포된 사이트에는 이 제한이 없어서 정상 작동합니다.
- 백업(내보내기/가져오기)은 JSON 파일 다운로드/업로드 방식 그대로 작동합니다.

## 로컬에서 확인하기

빌드 도구가 필요 없습니다. `index.html`을 더블클릭해서 브라우저로 열어도 대부분 기능이 바로 동작합니다.
(단, 일부 브라우저는 `file://`에서 fetch 계열 기능을 막을 수 있어 아래 방법을 추천합니다.)

```bash
npx serve .
# 또는
python3 -m http.server 5173
```

## 구글시트 연동 사용법

1. 앱 상단 관리(⚙️) 메뉴 → "시트 링크 또는 ID"에 구글시트 URL 붙여넣기
2. 시트 공유 설정이 "링크가 있는 모든 사용자 - 뷰어"인지 확인
3. 탭 이름 입력 (기본값: `기록`) — 실제 시트 탭 이름과 정확히 일치해야 함
4. "🔄 구글시트에서 새로고침" 클릭

시트 열 순서: A=날짜, B=카테고리명, C=금액, D=수입/지출, E=구분(할부 등), F=메모, G=비고, H=할부 실금액.
카테고리명은 앱에 등록된 이름과 정확히 같아야 인식됩니다.

## Vercel로 배포하기 (무료, 아이폰 설치까지)

### 1) GitHub에 올리기
1. github.com에서 새 저장소 생성 (예: `my-ledger`)
2. 이 폴더 전체를 그 저장소에 push:
   ```bash
   git init
   git add .
   git commit -m "가계부 배포 준비"
   git branch -M main
   git remote add origin https://github.com/<내계정>/my-ledger.git
   git push -u origin main
   ```

### 2) Vercel에 연결
1. vercel.com 가입 (GitHub 계정으로 로그인 가능)
2. "Add New... → Project" → 방금 만든 저장소 선택
3. Framework Preset: **Other** (또는 감지된 대로 두어도 됨) — 별도 설정 없이 "Deploy" 클릭
   - Build Command 비워두기, Output Directory `.` (루트) 그대로 두면 됩니다.
4. 배포 완료되면 `https://my-ledger.vercel.app` 같은 주소가 생깁니다.

### 3) 아이폰에 앱처럼 설치하기
1. 아이폰 **Safari**로 배포된 주소 접속 (Chrome 아님, Safari여야 함)
2. 하단 공유 버튼 → "홈 화면에 추가"
3. 홈 화면에 "나의 가계부" 아이콘이 생기고, 앱처럼 전체화면으로 실행됩니다.

## 주의할 점

- `localStorage`는 브라우저별로 따로 저장됩니다. 아이폰 홈 화면 앱과 컴퓨터 브라우저는 데이터가 공유되지 않습니다. 기기 간 데이터를 맞추려면 관리 메뉴의 "구글시트에서 새로고침"을 양쪽에서 실행하거나, 백업 JSON 내보내기/가져오기를 이용하세요.
- Safari 프라이빗 브라우징 모드에서는 `localStorage`가 세션 종료 시 사라질 수 있습니다.
